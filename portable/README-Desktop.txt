HexZero Windows 10/11 x64 原生桌面版（2026-10-23）

启动
完整解压后双击 START_HEX.bat，直接打开桌面窗口，无需浏览器、联网或安装 Python。
保留启动窗口直到对弈结束。首次启动会预热 ONNX 与 Numba，可能比之后稍慢。
CHECK_ENV.bat 检查 Tk、模型推理和搜索环境；错误日志位于 userdata/logs。
若 C++ 搜索不能运行，START_HEX_PYTHON.bat 使用 Python/Numba 搜索，仍采用 ONNX 推理。

默认配置
3250 轮模型、12800 次搜索、4 个推理线程，附带 Azalea 参考模型。
搜索上限可选 800、1200、2000、3200、6400、12800、51200，线程数可选 4～16。
模型保持 FP32，未量化；保留 C++ 批量搜索、树复用和节点内存保护。
搜索次数是上限，时间或节点预算耗尽时可能提前结束。

对弈规则
红方先手，连接上下；蓝方后手，连接左右。坐标 A1 位于左下，不使用交换规则。
己方可选择人类或 Azalea，对方固定为所选 HexZero 模型。
“手动设置开局”允许交替替双方落子；“完成开局”后再开始正常对弈。
人机对弈会自动回应；模型对战可用“下一手”或“自动对战”。
暂停会等待当前一手完成，不会从中间强制打断 ONNX/C++ 推理。

分析与棋谱
“候选分析”显示三个候选，按搜索访问次数排序。选择候选后可滑动预览后续变化。
预览不改变棋局；“采用选中的候选”仅允许在人类回合或手动开局时落子。
Q 是当前执棋方的局面价值，不是校准胜率；MARK -2～+2 代表局面优劣。
棋谱支持 GB2312 比赛 TXT 和 UTF-8 详细 JSON；后者保留评语与分析。
双击某手进入打谱，跳谱不截断原记录。“从此局面续弈”另建分支。
TXT 必须有赛果；尚未结束且没有裁定时请保存 JSON，不会编造胜负。
结束对局、切换模型和正常关闭窗口会保存棋谱到 userdata/games。

高级设置
随机种子默认 0，用于并列走法的随机选择和复现。最佳走法唯一时，改种子可能无效。
种子不是“棋力档位”或“随机开局”；要丰富开局应使用手动开局。
单步秒数为 0 时按搜索次数运行；每方总分钟为 0 时关闭棋钟。
比赛需要 30 分钟/方时，将总分钟设为 30 再新开局。启用限时后不同机器可能走出不同棋。

更换模型
将新模型 .onnx 与同名 .onnx.json 放入 models 的子文件夹，约 5 秒后可选或手动刷新。
切换前会校验模型并真实推理，文件不完整或哈希不一致会拒绝加载。
设置与当前模型选择保存在 userdata/settings.json，不会修改模型文件。

源码与许可
hex_desktop.py：原生窗口与事件；hex_play_core.py：对局、棋钟、打谱核心。
hex/desktop_service.py：串行工作线程接口、模型加载与环境检查。
hex/native/search.cpp：C++ MCTS；hex/native_mcts.py：Python ABI 适配。
ONNX 运行库和第三方许可证随包保留，Azalea 许可及修改说明在 app/hex/azalea_cpu。
本包不含开发测试、评测棋谱和报告。Windows C++ DLL 沿用已验证兼容版本；
桌面交互及真实模型已在 Linux 验证，新桌面界面仍需在目标 Windows 电脑运行确认。
